# Project Charter

## Project
**Highly Motivated Machine (HMM)**

## Brand personality
**Trust Me Bro** is the tongue-in-cheek public voice. HMM itself is skeptical, evidence-driven, and explicit about uncertainty.

## Mission
Build an autonomous market-intelligence system that finds abnormal crypto activity, investigates why it is happening, separates evidence from narrative, and exposes the result to humans and software agents.

## Problem
Crypto discovery is fragmented across exchange data, on-chain data, derivatives, social attention, governance, documentation, and news. Rapid price movement often causes narrative formation before evidence is verified.

## Proposed solution
HMM combines structured market telemetry with an evidence-backed research workflow. It detects anomalies first and researches them second rather than starting from a list of top gainers.

## Initial user
A crypto researcher or trader looking for early small-cap activity while needing explicit evidence, uncertainty, and risk flags.

## Non-goals for MVP
- autonomous leveraged trading
- custody of user funds
- guaranteed price prediction
- unsupervised live token deployment
- automated financial advice
- fabricated causal explanations for price movement

## Success criteria
The MVP succeeds when it can:
1. ingest and normalize multiple data sources;
2. establish rolling baselines;
3. identify statistically or rule-defined abnormal activity;
4. attach sourced evidence to a candidate catalyst;
5. classify catalyst confidence;
6. produce a repeatable HMM report;
7. expose results through a documented API;
8. demonstrate Bankr integration in simulation mode.
