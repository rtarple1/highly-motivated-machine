# Engineering Roadmap

## Phase 0 — Foundation
- repository standards
- data contracts
- ADRs
- threat model
- test harness
- mock providers
- CI

## Phase 1 — Scanner MVP
- Coinbase universe adapter
- market-data enrichment adapter
- normalized observations
- rolling baselines
- abnormal-activity rules
- CLI report

## Phase 2 — Intelligence
- research orchestrator
- source provenance
- catalyst classification
- sentiment adapters
- on-chain/network adapters
- Hype / Metrics / Mechanics scoring

## Phase 3 — Product/API
- FastAPI service
- report persistence
- user-facing dashboard
- API schema
- observability
- rate limiting

## Phase 4 — Agent economy experiment
- x402-paid endpoint
- Bankr simulation adapter
- treasury accounting model
- explicit human-approval workflow
- testnet/sandbox experiments where available

## Phase 5 — Production-readiness review
- security review
- legal/compliance review
- data-provider licensing review
- load testing
- incident response plan
- production deployment decision

### Portfolio checkpoints
Each phase should produce:
- code;
- tests;
- diagrams;
- an ADR for material decisions;
- screenshots/demo evidence;
- a short retrospective describing tradeoffs and lessons learned.
